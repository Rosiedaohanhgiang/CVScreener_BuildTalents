Ứng dụng này làm gì?

Sàng lọc & thẩm định ứng viên bằng AI: dán Mô tả công việc (JD) và Hồ sơ (CV), hệ thống chấm điểm mức độ phù hợp, phân tích điểm mạnh/yếu, cảnh báo rủi ro và gợi ý câu hỏi phỏng vấn — kèm báo cáo có logo để xuất PDF gửi khách.

3 bước sử dụng

1

Nhập API Key vào thanh trên cùng (bấm nút để lấy key miễn phí).

2

Dán JD và CV, hoặc bấm Tải Tư Liệu để nạp file (PDF, DOCX, TXT).

3

Bấm Kích hoạt Phân tích. Xuất báo cáo PDF bằng nút Report góc trên phải.

Quyền riêng tư

API Key và nội dung JD/CV không được lưu trên bất kỳ máy chủ nào. Chúng chỉ nằm trên trình duyệt của bạn và được gửi trực tiếp tới Google Gemini để phân tích. Mỗi người dùng dùng API Key riêng của mình.

Dữ liệu cá nhân của ứng viên: Với API Key gói miễn phí, Google có thể dùng dữ liệu gửi lên để cải thiện dịch vụ. Nên có sự đồng thuận của ứng viên, cân nhắc ẩn danh CV (bỏ tên/số điện thoại/CCCD) trước khi phân tích, hoặc dùng API Key trả phí có điều khoản không dùng dữ liệu để huấn luyện — phù hợp Nghị định 13/2023/NĐ-CP về bảo vệ dữ liệu cá nhân.

Tự động cập nhật

App tự chọn phiên bản model AI (Gemini Flash) mới nhất mà API Key của bạn có quyền dùng — không cần cài đặt hay cập nhật thủ công.

Lưu ý quan trọng

Kết quả do AI tạo ra chỉ mang tính tham khảo, hỗ trợ ra quyết định. Quyết định tuyển dụng cuối cùng luôn thuộc về chuyên gia nhân sự.
